Silabario

►Consonante + vocal.

►46 símbolos.

►Formas rectas y anguladas.

►Se usa mayormente para palabras de origen no japonés (o para enfatizar).

►Muchos préstamos y anglicismos, transcripciones fonéticas.

►A, KA, SA, TA, NA, HA, MA, YA, RA, WA.

Pronunciación

►ハ・ヒ・ヘ・ホ se pronuncian con una h aspirada, parecida a la j española suave: /ja/ /ji/ /je/ /jo/.

►フ no es fu española, es mezcla de fu/hu, fu de soplar sin dientes.

►ラ・リ・ル・レ・ロ se pronuncia como R suave; pera, cara, loro...

Alargaciones vocálicas

►Las alargaciones vocálicas se indican normalmente con el símbolo ー (chōonpu).

ケーキ - kēki - tarta/pastel
コーヒー - kōhī - café
ラーメン - rāmen - ramen
タクシー - takushī - taxi

Consonantes dobles

►Se utilizará ツ antes de la consonante para doblarla, excepto en ナ・ニ・ヌ・ネ・ノ que ya está ン.

►Cuando ツ se usa para doblar, se escribe con un tamaño más pequeño.

►No se pronuncia como /tsu/, el sonido que hará será el de la sílaba siguiente.

ベッド - beddo - cama

Tenten ゛ y maru ゜

►てんてん - tenten - rayitas.

►まる - maru - círculo.

K → G
S → Z
T → D
H → B
H → P

►Z: ザ・ジ・ズ・ゼ・ゾ /dsa/gi/dsu/dse/dso [/gi/ de Girona].

►D: ダ・ヂ・ヅ・デ・ド /da/ji/zu/de/do (se pronuncia como Z, se usa poco).

Combinaciones ヤ・ユ・ヨ

►Se usan con sílabas de i (キ、シ、チ、ニ、ヒ、ミ、リ、ギ、ジ、ヂ、ビ、ピ). Aunque habrá excepciones en las que no.

►ヤ・ユ・ヨ se escribirán después de la sílaba y serán más pequeñas.

►Usan el sonido de /i/.

►DI → ヂャ・ヂュ・ヂョ - ja ju jo (se pronuncia igual que Z (ji), se usa poco).

Palabras japonesas en katakana

►Se pueden escribir palabras japonesas que van en hiragana para expresar exageración, resaltarlas, jerga.

Ej: ヤバい (やばい) - yabai - terrible/tremendo

Nombres propios

►Los nombres propios se transcriben fonéticamente, se busca la aproximación.

María → マリア → Maria

►Si acaba en consonante se le añade vocal débil.

Inés → イネス → Inesu

►Si tiene L se pone R.

Lola → ローラ → Rōra

►Si tiene dos consonantes juntas se le añade vocal débil.

Alberto → アルベルト → Aruberuto

►Para separar el nombre de los apellidos se usará ・.

María López Fernández → マリア・ロペス・フェルナンデス → Maria Ropesu Ferunandesu

Sonidos que no existen: F, T, D, CH

►フ (porque tiene vocal débil) + a/i/e/o:

ファ - fa / フィ - fi / フェ - fe / フォ - fo

Felipe → フェリペ → Feripe

►TI/DI (al no haber con u, se usa con te):

ティ - ti / ディ - di

Martina → マルティナ → Marutina

►TU/DU (como la e ya se usa con ti/di, se usa to):

トゥ - tu / ドゥ - du

Dulce → ドゥルセ → Duruse

►CHE (el resto ya las tenemos):

チェ - che

Chema → チェマ → Chema

Sonidos que no existen: Ñ, LL

►Ñ, se usará combinación de NI + vocal.

ニャ - nya - ña
ニィ - nyi - ñi
ニュ - nyu - ñu
ニェ - nye - ñe
ニョ - nyo - ño

Cañedo → カニェド → Kanyedo

►LL, se usará combinación de RI + vocal.

リャ - rya - lla
リィ - ryi - lli
リュ - ryu - llu
リェ - rye - lle
リョ - ryo - llo

Vallejo → バジェホ → Bajeho

RR, Z, C, S, V

►RR es igual que R.

Carrasco → カラスコ → Karasuko

►ZA, CI, ZU, CE, ZO:

サ - sa - za / シ - shi - ci / ス - su - zu / セ - se - ce / ソ - so - zo

Cecilia → セシリア → Seshiria

►SI (el resto ya las tenemos):

シ - shi - si

Simón → シモン → Shimon

►V, se hará con バ/ビ/ブ/ベ/ボ.

Cuando un nombre o apellido acaba en Z, se usará ス.

Beatriz → ベアトリス → Beatorisu

Sonidos que no existen en español

►WI, WE, WU, WO

ウィ - wi / ウェ - we / ウ - u / ウォ - wo

water → wootā → ウォーター
web → webu → ウェブ
