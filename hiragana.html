Silabario

►Consonante + vocal.

►46 símbolos.

►Con formas redondeadas y curvas.

►Se usa para la mayoría de palabras japonesas excepto kanji.

►A, KA, SA, TA, NA, HA, MA, YA, RA, WA.

Pronunciación y partículas

►は・ひ・へ・ほ se pronuncian con una h aspirada, parecida a la j española suave: /ja/ /ji/ /je/ /jo/.

►Si は es partícula, después de sustantivo, se pronuncia como /wa/.

►ふ no es fu española, es mezcla de fu/hu, fu de soplar sin dientes.

►Si へ es partícula se pronuncia como /e/.

►ら・り・る・れ・ろ se pronuncia como R suave; pera, cara, loro...

►を se pronuncia como /o/ pero en rōmaji se escribe wo. Se usa como partícula, señala el Complemento Directo

おさけ を のみます か。
osake wo nomimasu ka? - ¿Bebes alcohol?

Alargaciones vocálicas

►Cuando se añade una vocal a una sílaba (sílaba + vocal).

え + い = /ē/.

お + う = /ō/.

►La misma vocal repetida alarga el sonido.

ああ = ā, いい = ī, etc.

おかあさん - okāsan
おにいさん - onīsan
ふつう - futsū
せんせい - sensē
ありがとう - arigatō

Consonantes dobles

►Se utilizará つ antes de la consonante para doblarla, excepto en な・に・ぬ・ね・の que ya está ん.

►Cuando つ se usa para doblar, se escribe con un tamaño más pequeño.

►No se pronuncia como /tsu/, el sonido que hará será el de la sílaba siguiente.

がっこう - gakkō - escuela

Tenten ゛ y maru ゜

►てんてん - tenten - rayitas.

►まる - maru - círculo.

K → G
S → Z
T → D
H → B
H → P

►Z: ざ・じ・ず・ぜ・ぞ /dsa/gi/dsu/dse/dso [/gi/ de Girona].

►D: だ・ぢ・づ・で・ど /da/gi/dsu/de/do (se pronuncia como Z, se usa poco).

Combinaciones や・ゆ・よ

►Sólo se usan con sílabas de i (き、し、ち、に、ひ、み、り、ぎ、じ、ぢ、び、ぴ).

►や・ゆ・よ se escribirán después de la sílaba y serán más pequeñas.

►Usan el sonido de /i/.

►DI → ぢゃ・ぢゅ・ぢょ - ja ju jo (se pronuncia igual que z(ji), se usa poco).
